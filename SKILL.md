# Tech Stack & Competency Requirements

## 1. Primary Technology Stack
*   **Language:** PHP 8.3+
*   **Framework:** Laravel 12+ (or latest stable)
*   **Database:** MySQL 8+
*   **Frontend HTML/CSS:** Laravel Blade templates, Tailwind CSS
*   **Frontend Scripting:** Vanilla JavaScript, Fetch API
*   **Map Integration:** Leaflet.js with OpenStreetMap
*   **Data Visualization:** Chart.js

## 2. Core Engineering Skills Required
*   **System Design:** Translating business rules into data models and REST API endpoints.
*   **Laravel Architecture:** Mastering Eloquent ORM, Service Layer pattern, API Resources, and Form Requests.
*   **API Development:** Building consistent, secure, and paginated RESTful endpoints with proper HTTP status codes.
*   **Authentication & Authorization:** Implementing role-based access control (RBAC) using Laravel Sanctum and Policies/Gates.
*   **Third-party Integration:** Consuming external APIs (Geocoding/Weather) using Laravel HTTP Client, handling timeouts and failures gracefully.
*   **Quality Assurance:** Writing automated feature and unit tests (PHPUnit/Pest).
*   **DevOps & Git Flow:** Maintaining clean commit histories, managing environment variables securely, and deploying to Cloud/VPS (Docker/GitHub Actions are a plus).
